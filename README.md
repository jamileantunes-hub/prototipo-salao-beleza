Protótipo Web - Sistema para Salão de Beleza

​Visão geral do projeto:

Este repositório apresenta o protótipo de alta fidelidade desenvolvido no Figma para um sistema de gestão e atendimento voltado a um salão de beleza. O projeto nasceu da prática de levantamento de requisitos junto ao cliente, focando em entender as reais dores do negócio para desenhar uma experiência de usuário simples, funcional e eficiente.

​Principais Etapas Desenvolvidas:
​Levantamento de Requisitos: Entrevistas e mapeamento das necessidades operacionais do salão.
​Arquitetura da Informação: Organização do fluxo de telas e navegação do usuário.
​Prototipagem (Figma): Desenvolvimento visual das telas web aplicando conceitos de usabilidade e clareza.
​Ferramentas Utilizadas:
​Figma (Prototipagem e design de interface)
​Técnicas de Análise de Requisitos

​Como visualizar e testar o projeto:
​Como este é um projeto de prototipagem visual e fluxo de interface, não há necessidade de instalação local ou configuração de servidor.
​Basta acessar o link público do Figma disponibilizado abaixo.
​Para navegar pelas telas de forma interativa, clique no botão de "Play" (Present) no canto superior direito da interface do Figma e teste os fluxos clicáveis como se estivesse usando o sistema real.
​Link de Acesso ao Protótipo:
​https://www.figma.com/design/rvN96uhjoUX6l28wfruEyR/Untitled?node-id=0-1&t=fPpVXK3mF9W0BNKT-1 

​O que aprendi com este projeto:

​Comunicação e Levantamento de Requisitos: Compreensão prática de como ouvir as necessidades de um cliente não técnico e traduzir essas demandas em funcionalidades claras de sistema.

​Pensamento Estruturado: Importância de organizar o fluxo de navegação e a arquitetura da informação antes de partir para a codificação.

​Foco no Usuário (UI/UX): Desenvolvimento da visão analítica de criar interfaces intuitivas que resolvem problemas reais do dia a dia.

​Como o projeto pode ser melhorado (Próximos Passos):

​Desenvolvimento Frontend e Backend: Transformar este protótipo em uma aplicação web funcional utilizando HTML, CSS, JavaScript, Python ou PHP e banco de dados MySQL.

​Automação e Inteligência Artificial: Integrar um agente de IA ou chatbot no fluxo de agendamento para automatizar o atendimento ao cliente, confirmar horários e responder dúvidas frequentes de forma inteligente.

​Responsividade: Expansão dos fluxos de tela com foco em dispositivos móveis (mobile-first).
